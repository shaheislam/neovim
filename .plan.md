## Current State

Audit complete. Highest-value gaps were `lua/plugins/kubectl.lua`, missing health checks, sparse LuaCATS coverage on custom modules, missing config validation, stale README content, and no CI beyond Docker image publishing.

DiffView migration is on the maintained `dlyongemallo/diffview.nvim` fork with the prior expanded fold behavior pinned. Validation found one local toggle bug in the custom conflict auto-switch watchers; deferred reopen callbacks now re-check `vim.g.diffview_auto_switch`, so `:DiffviewAutoSwitchToggle` actually disables conflict auto-switching after the view is already open.

Single-file `:DiffviewFileHistory` warnings on merge commit `16cbef1018...` were traced to `diff_merges = "combined"`: Git can emit `--numstat` lines without matching `--raw` entries for some merge commits, which makes DiffView's file-history parser skip them. The local workaround is to use `diff_merges = "first-parent"` for single-file history, which restores clean file-history output without changing repo history.

DiffView follow-up now adds three opt-in workflow improvements: persisted reviewed-file selections, a stash-history entrypoint, and an explicit `DiffviewSetRevs` command so an open review can be retargeted in place when only the revision range changes.
