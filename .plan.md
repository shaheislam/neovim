## Current State

The repo already has several execution/chat harnesses (`claude-code`, `codecompanion`, `opencode`, `agentic`) plus markdown rendering and strong quickfix support. The missing feature from the Parley article is a lightweight markdown review harness that treats inline review markers as first-class navigation and diagnostics data.

The parser subtask is implemented in `lua/parley/review.lua` with plain Lua assertions in `tests/parley_review_spec.lua`. It now also wires markdown buffers to `ParleyReviewRefresh` and `ParleyReviewQuickfix`, refreshes diagnostics on markdown editing events, and exposes `<leader>mr` / `<leader>mq` in `lua/plugins/markdown.lua`.

Validation passed with clean headless startup plus the end-to-end review workflow assertion. The only runtime note was an existing `image.nvim` warning about terminal size in non-terminal headless execution, which did not fail startup or the new tests.
