# Plan: TASK — client.request deprecation fix

## Objective

Eliminate the `client.request is deprecated` notification that appears in Neovim 0.12.1 when plugins use dot-notation LSP client methods (`client.request()` instead of `client:request()`).

## Approach

1. Identify source of deprecation warnings
2. Filter warnings from plugins in the vim.notify override (since noice routing is bypassed)
3. Update lazy-lock.json with latest plugin versions (some may have fixes)

## Progress

- [x] Root cause investigation
- [x] Add deprecation filter in vim.notify override (noice.lua)
- [x] Update lazy-lock.json with latest plugin commits

## Key Decisions

- User's own config is clean — ALL deprecation comes from third-party plugins (blink.cmp, nvim-lspconfig, rustaceanvim, fzf-lua, nvim-ufo, oil.nvim, yazi.nvim, nvim-nio, mini.nvim)
- The vim.notify override in noice.lua (line 131) sends notifications directly to nvim-notify, bypassing noice's route filters — this is why the existing `{ find = "checkhealth vim%.deprecated" }` filter on line 362 never fires
- Fix goes in the vim.notify override itself (not noice routes) since noice.notify is disabled (`enabled = false`)

## Success Criteria

- `client.request is deprecated` notification no longer appears
- All other notifications continue to work normally
- lazy-lock.json updated with latest plugin versions

## Current State

Root cause traced. Neovim 0.12 added a `method_wrapper` in `vim/lsp/client.lua` (line 255) that detects dot-notation calls and fires `vim.deprecate('client.' .. name, 'client:' .. name, '0.13')`. This goes through `vim.notify_once()` → `vim.notify()`. But the user's `vim.notify` override (noice.lua:131) sends directly to `require("notify")`, bypassing noice's routing and its skip filter.

Plugins still using dot notation (at latest commits): blink.cmp, nvim-lspconfig, rustaceanvim, fzf-lua, nvim-ufo, oil.nvim, yazi.nvim, nvim-nio, mini.nvim, sshfs.nvim.

Lazy sync updated 6 plugins: agentic.nvim, codecompanion.nvim, fzf-lua, mini.nvim, octo.nvim, yazi.nvim. Key offenders not updated (already at latest).
