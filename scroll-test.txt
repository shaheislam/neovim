--- Section 7: More padding for scroll length ---

The purpose of this section is simply to make the file long enough
that you can get a good feel for sustained scrolling behavior.

When scrolling through a file, the key things happening per-redraw are:
1. Statuscolumn evaluation (line numbers, signs)
2. Treesitter syntax highlighting
3. Indent guide calculation (blink.indent scope detection)
4. Gitsigns gutter updates
5. Incline floating statusline render
6. Any autocmd callbacks (WinScrolled, CursorMoved, etc.)

Each of these adds time to the redraw cycle. At 60fps, each frame
budget is 16.67ms. If the combined cost exceeds that, frames drop
and scrolling appears janky.

The fix applied in this branch removed the WinScrolled autocmd from
noice.lua. That autocmd was firing on EVERY scroll event in EVERY
window, iterating through windows and checking filetypes even when
no noice windows were open. This added unnecessary overhead to every
single scroll tick.

Other optimizations already in place:
- statuscolumn uses %l instead of %{v:lnum} (avoids Vimscript eval)
- synmaxcol=300 limits syntax highlighting to visible columns
- blink.indent has static guides disabled (scope-only)
- incline.nvim disabled globally in DiffView view_opened hook
- neoscroll replaced with native scrolling in diff buffers
- blink.pairs matchparen disabled per-buffer in diff views
- enhanced_diff_hl disabled (redundant with treesitter stop)
- marks.nvim excludes DiffView filetypes
- built-in plugins disabled early via vim.g.loaded_* guards
- vim.loader enabled for faster Lua module loading

If scrolling still feels janky after these fixes, investigate:
1. Check if a specific treesitter parser is slow (non-diff buffers)
2. Profile with :lua vim.lsp.set_log_level("off") to rule out LSP
3. Use :Lazy profile to identify slow plugin loads

You can profile Neovim's redraw with:
  :set eventignore=WinScrolled
  (scroll and compare)
  :set eventignore=

Or more thoroughly:
  nvim --startuptime /tmp/startup.log scroll-test.txt

And for runtime profiling:
  :profile start /tmp/profile.log
  :profile func *
  (scroll around)
  :profile stop
  (check /tmp/profile.log)
